# Goldman Sachs India Hackathon 2026 — Quant Challenge


NOTE - 
Most of the code is AI written for the 3 problems because it was a 12 hour hackathon and thus it's bound to contain bugs.



This repo contains the solutions and iteration history for the three problems, plus the final submission deck/report :

- [`p1/`](p1/README.md) — Regime Navigator: adaptive portfolio construction (regime-aware factor investing)
- [`p2/`](p2/README.md) — ETF proxy hedging & NAV replication
- [`p3/`](p3/README.md) — Bermudan swaption pricing (Hull-White calibration + tree/PDE pricer)
- [`charts/`](charts/) — regime, attribution, turnover, and exposure-transition plots (from P1)
- [`final_submission/`](final_submission/) — final slide deck and written report

Each problem folder's README walks through what changed version-to-version.


Along with that I have added guides (generated by AI) for the corresponding concepts required in each problem.
View with caution because it can contain mistakes. The purpose of adding them is to give viewers an idea of what prerequisites are generally required.
